2. User Interface

2.1. Overall Layout Idea
+----------------+--------------------------------------------+
|  __ISM         |  [ messages: errors / notices ]            |
|                |                                            |
|  Logged in as  |  Page content                              |
|  <username>    |                                            |
|  [Log out]     |                                            |
|                |                                            |
|  MAIN MENU     |                                            |
|   Home         |                                            |
|   Browse       |                                            |
|   My Cart      |                                            |
|                |                                            |
|  VENDOR TOOLS  |                                            |
|   My Stores    |                                            |
|   My Products  |                                            |
|   Create Store |                                            |
|   Add Product  |                                            |
+----------------+--------------------------------------------+

- A fixed sidebar for navigation for both Buyers and Vendors
    (Sidebar will look different for Buyers and Vendors based
    on their respective permissions).
- Visitors (not logged in) will see 'Log in' and 'Register'
- Messages like 'No stores/products present' will show at the
    top of the main content area .
- Smaller screens (mobile) the sidebar will move to the top and
    and product grid will drop to fewer columns
